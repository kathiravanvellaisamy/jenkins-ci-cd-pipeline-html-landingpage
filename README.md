# jenkins-ci-cd-pipeline-html-landingpage
This project demonstrates a simple CI/CD pipeline using Jenkins to deploy a small HTML website on AWS EC2. The pipeline automates build, test, and deployment processes to ensure continuous integration and delivery.


##Features:

1.Simple static HTML website
2.Jenkins CI/CD pipeline setup
3.Automated build & deployment
4.Hosted on AWS EC2 instance
5.GitHub integration with Jenkins

##Tech Stack:

HTML, CSS
Jenkins
AWS (EC2)
Git/GitHub

##How It Works:

1.Developer pushes code to GitHub
2.Jenkins fetches the latest code
3.Pipeline builds and deploys website to AWS
4.Website is served live via EC2
